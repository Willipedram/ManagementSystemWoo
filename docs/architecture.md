# معماری سامانه ManagementSystemWoo

این سند جزئیات معماری و اجزای اصلی سامانه را توضیح می‌دهد تا توسعه‌دهندگان بتوانند به سرعت با ساختار پروژه آشنا شوند.

## نمای کلی سیستم

- **لایه رابط کاربری (UI):** فایل `index.php` رابط مدیریتی تحت وب را ارائه می‌دهد. این رابط شامل ویزارد نصب، داشبورد آمار، مدیریت کاربران، لاگ فرایندها و تنظیمات است. تمامی تعاملات پویا از طریق درخواست‌های AJAX به `ajax.php` انجام می‌شوند.
- **لایه سرویس و API داخلی:** فایل `ajax.php` به عنوان نقطه ورود برای درخواست‌های AJAX عمل می‌کند. این فایل با توجه به مقدار `action` توابع مختلفی را برای مدیریت کاربران، سنجش سئو، هماهنگی با ChatGPT و زمان‌بندی فرایندها فراخوانی می‌کند.
- **لایه پردازش پس‌زمینه:** فایل‌های `worker.php` و `cron.php` برای اجرای فرایندهای زمان‌بندی‌شده (مانند استخراج داده‌های سرچ کنسول و محاسبه KPIها) استفاده می‌شوند. کلاس `ProcessQueue` صف فرایندها را مدیریت می‌کند و `ProcessManager` مسئول انتخاب و اجرای فرایندها است.
- **پایگاه داده:** سامانه با دو پایگاه داده کار می‌کند:
  - پایگاه داده ووکامرس که از طریق تابع کمکی `connect()` در فایل‌های کمکی متصل می‌شود.
  - پایگاه داده محلی سامانه که اطلاعات کاربران، لاگ‌ها، تنظیمات و خروجی‌های پردازش در آن ذخیره می‌شود.

## ماژول‌ها و کلاس‌ها

| کلاس | نقش | نکات کلیدی |
|------|-----|------------|
| `ChatGPTManager` | مدیریت تنظیمات و ارتباط با API های مبتنی بر ChatGPT | ذخیره امن کلید API با رمزنگاری AES، ثبت رویدادها در فایل لاگ، ارائه متد `testConnection` برای بررسی سریع اتصال. |
| `SEOAnalyzer` | تحلیل محتوای محصولات و پیشنهاد عنوان/متا | بررسی طول عنوان و متا، وجود کلمه کلیدی، ساختار هدینگ‌ها، لینک‌های داخلی و تصاویر. نتایج به صورت امتیاز و لیست جزئیات بازگردانده می‌شود. |
| `ProcessManager` | هماهنگی اجرای فرایندهای زمان‌بندی‌شده | اطمینان از وجود رکوردهای پیش‌فرض، اجرای فرایندهای `seo_score`، `gsc_fetch` و `user_kpi_daily`، ثبت زمان آخرین اجرا. |
| `ProcessQueue` | صف‌بندی و مدیریت وضعیت اجرای پردازش‌ها | ایجاد جدول صف در پایگاه داده محلی، ثبت وضعیت (pending/running/completed/failed)، علامت‌گذاری آغاز و پایان اجرا. |
| `UserManager` | عملیات CRUD روی کاربران سامانه | استفاده از `mysqli`، رمزنگاری رمزها با `password_hash`، مدیریت نقش‌ها و وضعیت کاربران. |
| `SanctionBypassManager` | مدیریت پروکسی/راهکار دور زدن تحریم‌ها | فراهم کردن لیست پروکسی و بروزرسانی وضعیت اتصال (برای تماس با سرویس‌های خارجی). |

## جریان‌های داده مهم

1. **راه‌اندازی اولیه:**
   - کاربر از طریق ویزارد `index.php` اطلاعات اتصال به پایگاه داده ووکامرس و پایگاه داده محلی را وارد می‌کند.
   - `ajax.php` پیکربندی را در فایل `local_config.secure` ذخیره می‌کند و جداول اولیه را با استفاده از `schema.sql` می‌سازد.

2. **امتیازدهی سئو محصولات:**
   - کران یا مدیر سامانه متد `ProcessManager::run('seo_score')` را فراخوانی می‌کند.
   - داده محصولات از ووکامرس خوانده می‌شود، با `SEOAnalyzer::analyze` بررسی شده و نتیجه در جدول `product_seo_scores` پایگاه داده محلی ذخیره می‌گردد.

3. **یکپارچگی با ChatGPT:**
   - مدیر سامانه از طریق تنظیمات، کلید API را ثبت می‌کند.
   - `ChatGPTManager` کلید را رمزنگاری و ذخیره می‌کند؛ متد `chat` برای ارسال درخواست به API OpenAI استفاده می‌شود و قدم‌ها در فایل لاگ ذخیره می‌گردد.

4. **زمان‌بندی فرایندها:**
   - `cron.php` فرایندهای فعال را بررسی کرده و موارد سررسیده را به صف اضافه می‌کند (`ProcessQueue::enqueue`).
   - `worker.php` صف را بررسی و پردازش‌ها را اجرا کرده و در صورت موفقیت یا خطا وضعیت را بروزرسانی می‌کند (`ProcessQueue::finish`).

## وابستگی‌ها و کتابخانه‌های خارجی

- **PHP 8.1+** برای پشتیبانی از ویژگی‌های زبان مورد استفاده در کلاس‌ها.
- **MySQL/MariaDB** برای ذخیره داده‌ها.
- **cURL و OpenSSL** برای ارتباطات HTTPS و رمزنگاری کلیدها.
- **کتابخانه‌های Front-end** (Bootstrap، DataTables، Select2، Chart.js و غیره) از CDN فراخوانی می‌شوند.
- **PHPUnit** برای اجرای تست‌های واحد (به کمک `composer test`).

## پرونده‌های پیکربندی کلیدی

- `local_config.secure`: اطلاعات اتصال پایگاه داده ووکامرس و پایگاه داده محلی.
- `chatgpt_config.json`: تنظیمات مربوط به ChatGPT (شامل کلید رمزنگاری شده، مدل و پارامترهای گفتگو).
- `dns_config.json` و `licenses.json`: برای مدیریت دسترسی به سرویس‌های جانبی.

## پیشنهادهای توسعه

- استفاده از الگوی Dependency Injection برای آسان‌تر شدن تست‌پذیری کلاس‌هایی که وابستگی مستقیم به `mysqli` دارند.
- افزودن لاگ ساختاریافته (Structured Logging) برای `ProcessManager` و `ProcessQueue` جهت ردیابی بهتر وضعیت پردازش‌ها.
- انتقال کلیدها و تنظیمات حساس به متغیرهای محیطی یا Secret Manager در محیط‌های تولیدی.
