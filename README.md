# ManagementSystemWoo

پنل مدیریت جامع برای فروشگاه‌های ووکامرس که امکاناتی مانند راه‌اندازی سریع، مدیریت کاربران، پردازش‌های زمان‌بندی‌شده، یکپارچگی با ChatGPT و تحلیل سئوی محصولات را فراهم می‌کند.

## ویژگی‌های کلیدی

- **ویزارد نصب سه مرحله‌ای** برای اتصال به پایگاه داده ووکامرس و پایگاه داده داخلی سامانه.
- **مدیریت کاربران** با نقش‌ها و سطح دسترسی قابل تنظیم.
- **داشبورد و گزارش‌ها** شامل KPI های کاربران، وضعیت سفارش‌ها و نمایش لاگ‌ها.
- **پردازش‌های زمان‌بندی‌شده** برای تحلیل سئو، همگام‌سازی داده‌های سرچ کنسول و محاسبه KPI.
- **تحلیل سئو محصولات** با استفاده از کلاس `SEOAnalyzer` و ذخیره نتایج در پایگاه داده داخلی.
- **یکپارچگی با ChatGPT** برای تولید محتوا، پاسخ به پرسش‌ها و پشتیبانی تیم.
- **مدیریت صف پردازش** از طریق کلاس `ProcessQueue` و سرویس‌های `cron.php` و `worker.php`.

## ساختار پروژه

```
├── index.php               # رابط کاربری اصلی و ویزارد نصب
├── ajax.php                # نقطه ورود درخواست‌های AJAX و API داخلی
├── worker.php / cron.php   # اسکریپت‌های پس‌زمینه و زمان‌بندی
├── classes/
│   ├── ChatGPTManager.php
│   ├── ProcessManager.php
│   ├── ProcessQueue.php
│   ├── SEOAnalyzer.php
│   ├── SanctionBypassManager.php
│   └── UserManager.php
├── docs/                   # مستندات تکمیلی (معماری، پیکربندی، تست)
├── tests/                  # تست‌های واحد مبتنی بر PHPUnit
├── schema.sql              # ساختار جداول پایگاه داده داخلی
├── chatgpt_config.json     # تنظیمات رمزنگاری شده ChatGPT
└── composer.json           # پیکربندی وابستگی‌ها و اتولود
```

## پیش‌نیازها

- PHP 8.1 یا جدیدتر با افزونه‌های `mysqli`, `curl`, `openssl`, `mbstring`, `dom`.
- MySQL یا MariaDB.
- Composer برای نصب وابستگی‌ها.
- دسترسی به اینترنت جهت دانلود بسته‌های Composer (در صورت نبود کش داخلی).

## نصب و راه‌اندازی سریع

```bash
git clone <repository-url>
cd ManagementSystemWoo
composer install
```

سپس دامنه یا آدرس سرور را در مرورگر باز کنید و مراحل ویزارد نصب را تکمیل نمایید. پس از اتمام، فایل‌های پیکربندی `local_config.secure` و `config.secure` ایجاد خواهند شد.

## پیکربندی

راهنمای جامع پیکربندی در فایل [`docs/configuration.md`](docs/configuration.md) موجود است. این راهنما شامل موارد زیر است:

- ساخت و ایمن‌سازی فایل‌های پیکربندی.
- ایجاد پایگاه‌های داده و اجرای `schema.sql`.
- تنظیم کران و سرویس‌های پس‌زمینه.
- نکات امنیتی و نگه‌داری.

## اجرای تست‌ها

```bash
# نصب وابستگی‌های توسعه (در صورت عدم انجام قبلی)
composer install

# اجرای تست‌ها
composer test
# یا
./vendor/bin/phpunit
```

> **نکته:** در محیط‌های با محدودیت شبکه، اجرای `composer install` ممکن است با خطای دسترسی به Packagist مواجه شود. در این صورت باید از آینه داخلی یا مخازن آفلاین استفاده شود.

## پوشش تست‌ها

تست‌های واحد فعلی بخش‌های زیر را پوشش می‌دهند:

- رمزنگاری و مدیریت تنظیمات ChatGPT (`ChatGPTManagerTest`).
- تحلیل سئو و پیشنهاد عنوان/متای محصولات (`SEOAnalyzerTest`).

برای اطلاعات بیشتر درباره ساختار و سناریوها به [`docs/testing.md`](docs/testing.md) مراجعه کنید.

## نگه‌داری و پیشنهادها

- وابستگی‌ها را به‌روز نگه دارید (`composer update`) و قبل از بروزرسانی از پایگاه داده و فایل‌های پیکربندی نسخه پشتیبان تهیه کنید.
- از HTTPS و محدودسازی IP برای دسترسی به پنل مدیریت استفاده کنید.
- برای افزایش تست‌پذیری، وابستگی‌های مستقیم به پایگاه داده در کلاس‌ها را با الگوی Dependency Injection یا لایه مخزن (Repository) جایگزین کنید.
- اجرای دوره‌ای تست‌ها را در فرآیند CI/CD سازمان ادغام نمایید.
